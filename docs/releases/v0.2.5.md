# 额度助手 v0.2.5

Release tier: GitHub community

> **Unsigned downloads:** the macOS package is not Developer ID signed or notarized, and the Windows package is not Authenticode signed. Download only from `H-bai01/quota-assistant` Releases and verify the package with `SHA256SUMS.txt`.
>
> **Windows Beta:** the Windows EXE includes automated build, manifest, SBOM, SHA-256, and artifact-attestation records, but has not completed real Windows GUI validation. It remains `beta-unvalidated` and is not listed as validated support.

## Changes

- 重整中英文 README 的信息层级并更新真实功能截图，让用途、下载入口和主要能力更容易理解。
- 在 README 中分别说明迷你浮窗、展开总览和仅在抓取失败且用户同意后运行的按需环境诊断。
- 从本版本源码生成 v0.2.5 的 macOS 社区版与 Windows Beta 安装包；本补丁版本不额外引入新的软件功能。

## Supported platforms

- macOS Universal：`quota-assistant_0.2.5_macos_universal.dmg`。macOS 是主要支持平台，实机验收记录写入本版本 `release-gates.json`。
- Windows x64 Beta：`quota-assistant_0.2.5_windows_x64-setup.exe`。自动构建与来源证明不能代替 Windows 实机 GUI 验收。

## Installation

从本版本 Release 下载对应安装包和 `SHA256SUMS.txt`。摘要不一致时不要运行安装包。

macOS：

```bash
shasum -a 256 quota-assistant_0.2.5_macos_universal.dmg
grep quota-assistant_0.2.5_macos_universal.dmg SHA256SUMS.txt
```

Windows PowerShell：

```powershell
Get-FileHash .\quota-assistant_0.2.5_windows_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

## Known limitations

- GitHub 社区版未使用平台开发者签名，macOS 或 Windows 可能要求用户确认来源。
- Windows Beta 尚未完成真实 Windows GUI、托盘、锁定、卸载和降级验收。
- 当前支持 Codex 与 Claude；其他 AI 工具将在后续版本逐步接入。
- 当前没有自动更新通道。

## Upgrade and rollback

- 退出旧版本后安装 v0.2.5；普通覆盖安装会保留本机设置和已保存摘要。
- v0.2.4 保留为上一公共版本。macOS 发布前会验证从 v0.2.5 降级到 v0.2.4 后仍可启动。
- Windows Beta 不声称具备已验证回退路径。

## Traceability

最终发布提交、构建来源、安装包摘要、平台结论和回退记录统一写入 `release-gates.json`、`SHA256SUMS.txt` 与 GitHub artifact attestation。
