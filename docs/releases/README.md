# 版本说明目录

每个待发布版本必须从 `docs/RELEASE_TEMPLATE.md` 创建一份 `<version>.md`，经审阅后随候选提交进入仓库。发布工作流只接受该目录下的简单 Markdown 文件，并验证 Changes、Supported platforms、Installation、Known limitations、Upgrade and rollback 五个必需章节。

不要在这里保存截图、账号信息、真实诊断、构建日志或私密实机证据；发布门只引用去敏后的持久 HTTPS 证据地址。
