# 额度助手 v0.2.2

Release tier: GitHub community

> **Unsigned downloads:** the macOS package is not Developer ID signed or notarized, and the Windows package is not Authenticode signed. Download only from `H-bai01/quota-assistant` Releases and verify every package with `SHA256SUMS.txt` before running it.
>
> **Windows preview:** the Windows EXE has passed automated build, manifest, SBOM, SHA-256, and artifact-attestation checks, but has not completed real Windows GUI validation. Installation, cold start, compact/expanded modes, drag, always-on-top, tray, lock/unlock, both languages, diagnostics copy, quit, uninstall, and downgrade are not claimed as validated.

## Changes

- 强化 Codex、Claude 登录与订阅读取的安全边界：固定官方 HTTPS origin，凭据不进入 WebView JavaScript、URL、页面、日志、诊断或错误。
- 增加登录轮询终止、购买来源重新确认，以及订阅缓存的大小、版本、原子写入和损坏恢复保护。
- 完善 macOS 与 Windows 诊断、剪贴板和安装包运行边界；macOS 使用精确远端附件完成实机验收，Windows 以明确未验收的预览版提供。
- 重做中英文 README：展示额度助手 Logo、居中的标题与语言入口，以及 Codex、Claude 均有有效数据的双服务界面；保留直接下载、首次使用、故障排查和 SHA-256 验证说明。
- 加强发布治理，阻止 HTML 注释掩盖 README 可见结构，并拒绝未闭合或无对应开头的 HTML 注释标记。
- 发布流程采用固定依赖、最小权限、单一发布者、SBOM、GitHub artifact attestation 和统一 SHA-256；macOS 实机门保持强制，Windows v0.2.2 只允许在完整风险披露下作为未验收预览版发布。

## Supported platforms

- macOS Universal：附件为 `quota-assistant_0.2.2_macos_universal.dmg`，未使用 Developer ID 签名或 Apple 公证；已使用精确远端附件完成真实 Mac 验收与降级。
- Windows x64 预览版：附件为 `quota-assistant_0.2.2_windows_x64-setup.exe`，未使用 Authenticode 签名；尚未完成 Windows 实机 GUI 验收，不列为已验证支持。
- 二进制附件由 Candidate 源提交 [`a28df7a21a5a84429db81d0770f0cf16f78dc95b`](https://github.com/H-bai01/quota-assistant/commit/a28df7a21a5a84429db81d0770f0cf16f78dc95b) 构建。`release-gates.json` 分别记录二进制源提交、最终发布提交、macOS 验收证据及 Windows `preview-unvalidated` 状态，不会为 Windows 生成虚假实机证据。

## Installation

1. 从同一 GitHub Release 下载平台安装包、`SHA256SUMS.txt` 和 `release-gates.json`。
2. 使用 SHA-256 工具核验安装包；摘要不一致时立即停止。
3. macOS 可能显示 Gatekeeper 警告；Windows 可能显示 SmartScreen 或“未知发布者”警告。仅在确认官方仓库来源、摘要和 GitHub artifact attestation 后继续。

Windows EXE 是预览版，只建议在能够承担预览软件风险的环境中使用；自动构建与来源证明通过不代表 Windows GUI 行为已经验证。

macOS：

```bash
shasum -a 256 quota-assistant_0.2.2_macos_universal.dmg
grep quota-assistant_0.2.2_macos_universal.dmg SHA256SUMS.txt
```

Windows PowerShell：

```powershell
Get-FileHash .\quota-assistant_0.2.2_windows_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

## Known limitations

- 未签名社区版可能触发 Gatekeeper、SmartScreen 或安全软件误报。
- Codex 与 Claude 的非公开只读接口、页面结构或认证方式变化时，相关数据可能暂时不可用；应用不会猜测额度。
- Google Play 与网页直付订阅读取尚未完成真实账号验证。
- Windows v0.2.2 尚未完成真实安装、冷启动、紧凑/展开、拖动、置顶、托盘、锁定/解锁、双语、诊断复制、退出、卸载和降级验收。
- 当前未启用安全自动更新通道。

## Upgrade and rollback

- 升级前退出旧版本，再安装 v0.2.2。
- v0.2.1 保留为上一公共版本，公开附件与校验文件必须继续可下载并通过校验。
- macOS 已完成从本候选降级至公开 v0.2.1 并验证启动；Windows 预览版没有降级验证，不得声称 Windows 可安全回退。权威结论见 Release 附件 `release-gates.json`。

## Traceability

- 最终发布提交、二进制 Candidate 源提交、构建工作流 run ID、两平台安装包摘要、macOS 验收与回退证据，以及 Windows 预览状态，记录在 Release 附件 `release-gates.json`。
- 安装包、SBOM、manifest 和 `release-gates.json` 的摘要统一记录在 Release 附件 `SHA256SUMS.txt`。
- 构建来源通过 GitHub artifact attestation 关联到本仓库及对应构建工作流；下载后应验证 attestation。
- SBOM 附件为 `quota-assistant_0.2.2_windows.cdx.json` 和 `quota-assistant_0.2.2_macos.cdx.json`。
