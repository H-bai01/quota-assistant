# 额度助手 v0.2.3

Release tier: GitHub community

> **Unsigned downloads:** the macOS package is not Developer ID signed or notarized, and the Windows package is not Authenticode signed. Download only from `H-bai01/quota-assistant` Releases and verify every package with `SHA256SUMS.txt` before running it.
>
> **Windows Beta:** the Windows EXE includes automated build, manifest, SBOM, SHA-256, and artifact-attestation records, but has not completed real Windows GUI validation. Installation, cold start, compact/expanded modes, drag, always-on-top, tray, lock/unlock, both languages, diagnostics copy, quit, uninstall, and downgrade are not claimed as validated.

## Supported platforms

- macOS Universal：附件名为 `quota-assistant_0.2.3_macos_universal.dmg`；未使用 Developer ID 签名或 Apple 公证。实机验收结论以本版本 Release 附件 `release-gates.json` 为准。
- Windows x64 Beta：附件名为 `quota-assistant_0.2.3_windows_x64-setup.exe`；未使用 Authenticode 签名。自动构建与来源证明不能替代 Windows 实机 GUI 验收，因此不列为已验证支持。
- `release-gates.json` 记录精确发布提交、Candidate run、macOS 实机证据和 Windows `beta-unvalidated` 状态；不会为 Windows 生成虚假实机证据。

## Installation

1. 从本版本 GitHub Release assets 下载对应安装包、`SHA256SUMS.txt` 和 `release-gates.json`。仓库右侧 Packages 为空是正常的。
2. 核对 SHA-256；摘要不一致时不要运行安装包。
3. macOS 可能显示 Gatekeeper 警告，Windows 可能显示 SmartScreen 或“未知发布者”警告。仅在确认仓库来源、摘要和 artifact attestation 后继续。

macOS：

```bash
shasum -a 256 quota-assistant_0.2.3_macos_universal.dmg
grep quota-assistant_0.2.3_macos_universal.dmg SHA256SUMS.txt
```

Windows PowerShell：

```powershell
Get-FileHash .\quota-assistant_0.2.3_windows_x64-setup.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

## Known limitations

- GitHub 社区版未签名，可能触发 Gatekeeper、SmartScreen 或安全软件提示。
- Windows Beta 尚未完成真实安装、冷启动、紧凑/展开、拖动、置顶、托盘、锁定/解锁、双语、诊断复制、退出、卸载和降级验收。
- Codex、Claude 的页面结构、认证方式或非公开只读接口变化时，数据可能暂时不可用；程序不会猜测额度。
- 当前未启用安全自动更新通道。

## Upgrade and rollback

- 升级前退出旧版本，再安装 v0.2.3。
- v0.2.2 保留为上一公共版本；正式发布前必须重新验证其附件和校验文件仍可下载。
- macOS 的本版本降级结论以 `release-gates.json` 中的真实证据为准。Windows Beta 不声称具备已验证回退路径。

## Traceability

- 最终提交、Candidate run、安装包摘要、平台结论和回退记录统一写入 `release-gates.json`。
- 安装包、SBOM、manifest 和 `release-gates.json` 的摘要统一写入 `SHA256SUMS.txt`。
- 构建来源由 GitHub artifact attestation 关联到本仓库和对应工作流。
