# 额度助手 0.2.1

## 0.2.1 changes

- Rebuilt compact-window dragging to follow pointer movement directly, preventing rollback and accidental expansion.
- Reduced the compact widget from 152×152 to 120×88 and tightened icon, type, spacing, and edge snapping.

额度助手 is a local-first floating desktop widget for checking Codex and Claude quotas and confirmed subscription renewal dates.

## Downloads

- Windows unsigned installer generated by Tauri.
- macOS Universal app/DMG generated by Tauri (Apple Silicon + Intel).

The locally verified macOS candidate is Apple Silicon (`aarch64`). GitHub Actions produces the Universal macOS release candidate.

## Install

1. Sign in to Codex Desktop on the same machine.
2. Download the package for your platform from this repository's Release.
3. Install and run the app, then use **Connect Claude** if Claude monitoring is required.
4. Use **Get subscription information** to confirm renewal dates through the official service or billing page.

### macOS signing and notarization note

This macOS build has no Developer ID signature and is not notarized. A local build may have an ad-hoc signature, which does not remove Gatekeeper warnings. If macOS blocks the first launch:

1. Right-click the app and choose Open.
2. Choose Open again in the system prompt.
3. If needed, allow the app in System Settings -> Privacy & Security.

## Privacy

额度助手 does not copy Codex tokens, Claude/Apple cookies, passwords, account IDs, prompts, chats, raw responses, or local auth paths into its own data. It stores widget preferences and a minimal subscription summary. See `PRIVACY.md`.

## Notes

- This release is unsigned. Windows may show an unknown publisher warning; macOS may show a Gatekeeper warning.
- Codex quota is read from non-public quota service responses and may stop working if the response shape changes.
- The app shows stale/unavailable states instead of estimating quota.
- Windows and macOS builds share the same React/CSS UI and behavior layer.
- Automatic updates are not enabled. Upgrade or roll back only with packages from this repository's Releases.
- To uninstall, remove the app. Removing its application data as well will also clear preferences, saved WebView sessions, and the subscription summary.
