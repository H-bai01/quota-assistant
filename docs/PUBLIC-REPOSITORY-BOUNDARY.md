# 公开仓库文件边界

`.github/public-files.json` 是公开源码包的精确 allowlist。发布治理检查读取 Git 已跟踪文件与待加入的新文件；未列出的新文件默认失败，必须先审阅公开用途再显式加入。

## 可以公开

- 运行源码、确定性测试与构建配置；
- 面向用户的 README、隐私、安全、许可证和安装说明；
- 面向贡献者的开发、测试、候选构建和发布治理文档；
- 自有或已记录来源与权利状态的必要桌面图标；
- 不含账号、用户路径或真实数据的通用自动化脚本。

## 禁止公开

- `.env`、token、Cookie、私钥、签名证书、真实账号配置；
- 本机绝对路径、运行日志、缓存、target、node_modules、恢复 bundle；
- 用户截图、原始诊断、私密测试记录、真实订阅或账号数据；
- 内部用户反馈跟踪表、一次性设计验收记录、内部过程生成器；
- 未确认再分发权利的第三方品牌资源；
- 安装包、临时候选包和发布后手工改写的附件。

本轮从公开候选树移除了 `design-qa.md`、`docs/USER-FEEDBACK-TRACKER.md` 和三个反馈表生成脚本。这些属于内部过程材料，不是用户或贡献者完成构建所需的内容。

denylist 在 allowlist 之外再次拒绝常见凭据、缓存、恢复包、日志和本机证据路径。文本检查还拒绝个人绝对路径与常见密钥形态；历史凭据扫描仍须作为发布前独立检查执行。
